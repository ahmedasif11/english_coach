# Product Overview

English Coach is a single-user speaking practice app. The person opens it, presses start, and talks. The app listens, replies briefly, points out the most useful mistake, and remembers patterns for the next session.

It is a learning loop, not a chatbot.

```text
Listen → understand → evaluate → pick one weakness → teach briefly → practice → remember → pick the next focus
```

## What the person should feel

> I open this, press one button, start talking, and it helps me improve my English without asking me what to study.

## What this is not

- A multi-user product
- A lesson marketplace
- A dashboard of scores
- A general voice assistant
- A cloud service



## MVP

The first usable version does this:

```text
Open app → speak → local transcription → short coach reply → one grammar correction → the mistake is stored → the next session uses it
```

Pronunciation scoring, vocabulary drills, and a metrics dashboard wait until that loop is reliable.

## Experience

No setup screen for grammar rules, prompts, topics, or lesson plans. The first launch runs a short diagnostic conversation. Later launches show today's focus and a start button.

The person should speak more than the coach. Coach replies stay short. Corrections show the original line, a better line, one rule, and a prompt to say it again.

## Success

A session is successful when the person spoke, received at most one or two focused corrections, and the stored profile changed in a way the next session can use.
